This is the official library system for the SIB Paguokon Rebana Dance Library. This platform provides easy access to dance learning materials, instructional videos, music, documents, and other resources while helping administrators manage the digital library efficiently.
## Project Demo Video

This video demonstrates the features and functionality of the SIB Paguokon Rebana Dance Library, a web application developed for private organizational use.

The website allows registered members to access rebana dance tutorial videos, while administrators can manage the library's content.

**Technologies used:** PHP, MySQL, HTML, CSS, JavaScript.
